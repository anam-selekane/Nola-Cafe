# Nola Cafe
Nola Cafe is a local cafe in Gqeberha

# Project Overview
Nola Cafe website is designed to promote the business through social media and attract more customers around the province making it more visible

# Purpose of the website 
the purpose of the website is to:
-To provide more information about Nola Cafe
-Display Cafe Menu
-Allow customer to contact the cafe
-Allow customers to send enquiry

# Pages Included
-Homepage
-About Nola Cafe/Staff members
-Menu
-Contact Details
-Enquiry Form
