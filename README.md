## 3. Project Overview

Nola Café is a local café based in Walmer, Port Elizabeth (Gqeberha). The café was established in 2018 with the aim of bringing people together through great food, desserts and exceptional coffee.

The Nola Café website was developed to promote the business, increase its online visibility and provide customers with useful information about the café. The website allows visitors to explore the menu, learn about the café, view its location and submit enquiries.

The website uses a brown and beige colour scheme to create a warm and welcoming café atmosphere.

## 4. Website Goals and Objectives

The main goal of the Nola Café website is to promote the growth and visibility of the business.

The objectives are:

- **Increase website traffic:** Attract more visitors by showcasing the café's food, drinks and atmosphere.
- **Generate enquiries:** Allow potential customers to contact the café through online enquiry forms.
- **Promote products:** Display the café's food, beverages, desserts and special offers.
- **Provide information:** Give customers access to the café's location, contact information and opening hours.
- **Improve customer experience:** Provide an accessible and easy-to-navigate website on desktop, tablet and mobile devices.

## 5. Website Pages and Features

### Home Page

- Introduces Nola Café.
- Displays a welcome message.
- Provides links to the menu and enquiry page.
- Highlights the café's food, coffee and atmosphere.

### About Us Page

- Provides the history of Nola Café.
- Displays the mission and vision statements.
- Explains the target audience.
- Introduces the café's staff members.
- Includes additional information about the business.

### Menu Page

- Displays food and beverage items.
- Includes menu categories.
- Provides menu search functionality.
- Allows visitors to filter menu items by category.
- Displays food and beverage pictures and prices.
- Includes special menu items.

### Contact Us Page

- Displays the café's contact information.
- Provides opening hours.
- Shows the café's location.
- Includes an embedded Google Map.
- Provides contact and enquiry information.

### Enquiry Page

- Provides an online enquiry form.
- Collects customer names and email addresses.
- Includes telephone number and enquiry subject fields.
- Provides preferred contact methods.
- Allows customers to select a preferred visit date.
- Includes a message field and consent checkbox.
- Includes submit and reset buttons.
- Uses JavaScript to validate form information.

## 6. Technologies Used

The following technologies were used to develop the website:

- **HTML5:** Used to structure the website and its content.
- **CSS3:** Used to style the website, including colours, typography, layouts and responsive design.
- **JavaScript:** Used to add interactive functionality such as navigation, menu filtering, date and time display, and form validation.
- **Google Fonts:** Used to include custom typography.
- **Google Maps:** Used to display the café's location.

## 7. Responsive Design

The website was designed to support different screen sizes.

- **Desktop:** Displays the website with a full navigation layout and structured content.
- **Tablet:** Adjusts the layout, images and navigation to fit medium-sized screens.
- **Mobile:** Uses a compact navigation menu and adjusts content to fit smaller screens.

Media queries are used to adjust the website layout according to screen size.

Responsive testing screenshots should be saved in the `screenshots` folder.
